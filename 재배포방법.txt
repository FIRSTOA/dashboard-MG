============================================
  결과표 GAS 재배포 방법 (윈도우 PC 기준)
============================================

※ 언제 하나요?
   - "GAS 재배포하세요" 라고 안내받았을 때만 하면 됩니다.
   - 화면(대시보드)만 바뀐 변경은 재배포 필요 없음 (자동 반영).


--------------------------------------------
1단계) 명령창 열기
--------------------------------------------
   윈도우키 + R  ->  cmd 입력  ->  엔터
   (또는 시작메뉴에서 "명령 프롬프트" 검색)

   이렇게 뜸:  C:\Users\MYCOM>


--------------------------------------------
2단계) 폴더 들어가기
--------------------------------------------
   cd dashboard-MG

   -> 앞이 C:\Users\MYCOM\dashboard-MG> 로 바뀌면 성공


--------------------------------------------
3단계) 최신 코드 받기
--------------------------------------------
   git pull


--------------------------------------------
4단계) Apps Script에 올리기
--------------------------------------------
   clasp push

   -> "Pushed 2 files" 나오면 성공


--------------------------------------------
5단계) 배포하기 (같은 주소 유지)
--------------------------------------------
   clasp deploy -i AKfycbzLU4a0Jvq_G5ZJIAVCgnLm48ca0Q9IaMVuMe7NQpLIomvruZ_kJ4BwRBrNRHicz5N40A -d "update"

   -> "Deployed ... @12" 처럼 나오면 끝


--------------------------------------------
6단계) 대시보드 새로고침
--------------------------------------------
   앱에서 새로고침(↻) 누르기. 주소는 그대로 두면 됨.


============================================
  익숙해지면: 3~5단계를 한 줄로
============================================

git pull && clasp push && clasp deploy -i AKfycbzLU4a0Jvq_G5ZJIAVCgnLm48ca0Q9IaMVuMe7NQpLIomvruZ_kJ4BwRBrNRHicz5N40A -d "update"


============================================
  잘 안 될 때
============================================
- "clasp 명령을 찾을 수 없음"  -> dashboard-MG 폴더 안에 있는지 확인 (2단계)
- "Apps Script API" 에러       -> https://script.google.com/home/usersettings 에서 API ON
- 로그인 풀림                   -> clasp login 다시 한 번
- -i 뒤 긴 ID 는 항상 똑같음. 위에 적힌 것 그대로 사용 -> 같은 주소 유지됨


배포에 쓰는 웹앱 주소 (대시보드 [결과표 연동]에 넣는 주소):
https://script.google.com/macros/s/AKfycbzLU4a0Jvq_G5ZJIAVCgnLm48ca0Q9IaMVuMe7NQpLIomvruZ_kJ4BwRBrNRHicz5N40A/exec
